This document is the **source of truth** for UI copy. The Web client's i18n
dictionaries (`packages/views/src/i18n/locales/{en,zh-CN,ja}.ts`) derive their
keys and translations from the tables below. When a label changes, update it
here first, then the dictionaries.

Chinese copy is **verb-first** (动词优先): "添加"、"分配"、"触发" — never
"进行 XX 操作".
