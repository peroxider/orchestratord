orchestratord is a multi-agent orchestration daemon that fronts a fleet of
CLI coding agents behind a single SPI. It preserves orchestratord's core
advantages — the SPI/plugin mechanism, a central capability matrix with forced
degradation, agent-callable skills with verifiable source references, and
in-process multi-agent mode — while adding a product-grade Web client,
PostgreSQL persistence, multi-tenancy, and multi-VCS integration.

## Highlights

- **SPI + plugins** — every agent backend is a plugin behind one interface.
- **Capability matrix** — central capability declarations with forced
  degradation when a backend overstates itself.
- **Agent-callable skills** — filesystem skills with verifiable source-map
  references, safe for agents to invoke.
- **In-process multi-agent** — run multiple agents within one process.
