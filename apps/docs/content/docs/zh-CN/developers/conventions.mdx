本文档是 UI 文案的 **source of truth**。Web 客户端的 i18n 字典
（`packages/views/src/i18n/locales/{en,zh-CN,ja}.ts`）的键与译文均派生自下表。
修改文案时，先改这里，再改字典。

中文文案遵循 **动词优先**：使用"添加"、"分配"、"触发"，不使用"进行 XX 操作"。
